# Amazon ML Solution - Business Entity Resolution

This package contains the end-to-end pipeline for the Business Entity Resolution Challenge.

## Directory Structure
- `src/`: Core source code (preprocessing, blocking, feature extraction, modeling, inference).
- `output/`: Generated submission files (`matching_results.tsv` and `candidate_pairs.tsv`).
- `experiments/`: Experiment tracking, validation scripts, and ablation studies.
- `notebooks/`: Jupyter notebooks for exploratory data analysis (EDA) and prototyping.
